# ARINE Ecosystem

Marketing website for the ARINE growth ecosystem, built with Next.js App Router.

## Run locally

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Home
- `/services` — Meta Automation, Creative Engine, Search Engine Automation, Online Store Management, CRM, SEO, GEO, and Operations
- `/guide` — Growth and campaign guides
- `/resources` — Resource directory
- `/resources/about` — About ARINE
- `/resources/policies` — Policy information
- `/resources/careers` — Careers contact
- `/resources/events` — Events
- `/pricing` — Plans and pricing

Pricing is displayed in INR: a 15-day free trial, ₹3,000/month for 1,200 credits, ₹15,000/month for 8,000 credits, and an Enterprise plan by inquiry.
